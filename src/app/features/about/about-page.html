Team collaboration

We divided the project into the main application components, such as the Home, Catalog, Product Details, Cart, Login, Registration, Profile, Wishlist, About Us, and 404 pages. Each team member took ownership of specific parts of the project, breaking them down into smaller tasks and working on them independently. Throughout the project, we stayed connected through our Discord channel, where we shared progress updates, discussed ideas, asked for help when needed, and solved problems together. Our mentor guided us whenever we faced challenges, provided valuable feedback, and developed a custom backend that supported the application's functionality. We used Git and GitHub to manage the source code, with everyone working on their own branches and merging completed features into the main project after review.
