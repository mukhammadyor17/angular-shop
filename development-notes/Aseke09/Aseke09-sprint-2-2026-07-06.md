## Problems

* `price` and `rating` came back from the backend as strings, causing TypeScript arithmetic errors in `CartService`.
* `CartService` total calculation broke after the `Product` interface update.
* Cart items disappeared on page reload because signal state is in-memory only.
* `MatBadge` was not working because `MatBadgeModule` was imported at the top but not added to the component `imports` array.
* Add to cart from the Home page was silently doing nothing — the `(addToCart)` event binding was missing from the template.

## Solutions

* Changed `price` and `rating` to `string` in the `Product` interface and used `Number()` cast in the total calculation.
* Used `effect()` in `CartService` to automatically write to `localStorage` on every signal change and initialized the signal from `localStorage`.
* Added `MatBadgeModule` to the `@Component` imports array in `PageHeader`.
* Added `(addToCart)="onAddToCart($event)"` binding to `app-product-card` in `home-page.html`.

## What I learned

* How `toSignal()` automatically handles subscription and unsubscription — replacing `ngOnInit` and `ngOnDestroy`.
* How `effect()` reacts to signal changes as a side effect — useful for syncing state to external storage.
* How `computed()` derives reactive values from signals without manual recalculation.
* How to read route parameters reactively using `paramMap` and `switchMap` for the product details page.
* How Angular Material `MatBadge`, `MatSnackBar`, and `MatProgressSpinner` integrate with signal-based components.
* Why returning a `UrlTree` from a guard is better than calling `router.navigate()` directly.
